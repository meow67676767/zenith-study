# 🌟 Zenith Study (Android)

> **Автономный многоагентный академический ассистент нового поколения**  
> Спроектирован для решения школьных и олимпиадных задач (СОР, СОЧ, ЕНТ/ЕГЭ) без шаблонности ИИ.

---

## 🚀 Ключевые возможности

- **🧠 Трёхэтапный конвейер решения (Multi-Agent Pipeline):**
  1. **Декомпозиция (DeepSeek-V3 / Claude Opus):** Разбиение задачи на шаги, скрытые ловушки и ограничения.
  2. **Решение и Факт-чекинг (GLM-5.3-Flash / Perplexity):** Генерация строгих математических формул (KaTeX), чертежей геометрии (векторный SVG) и проверка дат/терминов через live web-поиск.
  3. **Стилизация под человека (BETA Anti-AI):** Переписывание ответа живым языком школьника без характерных для ИИ маркеров («Таким образом», «Подводя итоги», стерильная структура).

- **📐 Встроенный интерактивный рендерер:**
  - Нативная визуализация геометрических чертежей и графов в SVG.
  - Поддержка формул любой сложности через KaTeX.
  - Превью интерактивных HTML-виджетов прямо внутри чата.

- **🛡️ Контроль квот и безопасность (Supabase Realtime):**
  - Разделение на роли: `admin` (владелец, безлимитный доступ) и `friend` (дневной лимит запросов).
  - Удалённая блокировка и управление пирами в реальном времени.
  - Защита пин-кодом для панели администратора.

- **🎲 Мини-игра «Дежурный Завуч»:**
  - Если у друга закончились запросы, приложение открывает экзаменационный диалог со строгим ИИ-завучем (`glm-5.3-flash`).
  - При решении академической загадки или аргументированном объяснении начисляются бонусные `+5` запросов.

- **📷 Нативная камера и галерея Samsung:**
  - Прямой вызов системного селектора Android без зависаний.

## 🛠️ Стек технологий

- **Фреймворк:** React 19 + TypeScript + Vite + Tailwind CSS
- **Мобильный рантайм:** Capacitor 8 (Android 14+, One UI 6+)
- **База данных и синхронизация:** Supabase PostgreSQL 17 + Realtime WebSockets
- **ИИ-бэкенд:** ChatWave High-Speed Proxy (Claude 3.7 / Opus, GPT-5, GLM-5.3-Flash)
